## Description:
The techshell project is an emulation of a bash shell that interprets user input as a shell command and performs actions how they would be performed in a normal bash shell.

## Instructions:
Go to the techshell.c file in the repository and copy the code, then paste it in your IDE, right click the file and press "Open in Integrated Terminal." From there, type in "gcc techshell.c -o techshell" and press enter. Then, type "./techshell" and press enter.

## Features and How to Use:
### Working:
- Change directory: cd [name]
- Print directory: pwd
- List contents: ls
- Process status: ps [options]
- Change mode: chmod [permissions] [filename]
- Word count: wc [options] [filename]
- Concatenate: cat [filename]
- Remove: rm [filename]
- Exit: exit
